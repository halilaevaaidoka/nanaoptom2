# SENSULU — Web Technologies Project

## Project Description

This project is a multi-page website about the SENSULU decorative cosmetics brand. It was created for the Introduction to Web Technologies course.

Assignment 1 focused on HTML5 structure and semantic markup. Assignment 2 continues the same project and adds CSS styling, layouts, selectors, positioning, and cascade experiments.

## Pages

* index.html — Home page
* products.html — SENSULU products and prices
* order.html — Product order form
* about.html — Information about the SENSULU brand
* feedback.html — Customer feedback form
* colophon.html — Information about the website project

## Technologies

* HTML5
* CSS3
* Visual Studio Code
* Git
* GitHub

The website runs locally in a web browser. JavaScript, CSS frameworks, and website builders are not used.

## Assignment 2 — CSS Styling

### Stylesheets

* css/base.css — Shared styles used across the website.
* css/aida.css — Styles for the Products and Order pages.
* css/assiya.css — Styles for the About and Feedback pages.

### CSS Features

The project demonstrates CSS techniques studied in the course, including:

* Flexbox
* CSS Grid
* Type, class and ID selectors
* Child and descendant selectors
* Attribute selectors
* Pseudo-classes and pseudo-elements
* Static, relative, absolute and fixed positioning
* Float and clear
* Different centering techniques
* CSS cascade and specificity

## Forms

The Order and Feedback pages contain HTML forms. The forms demonstrate different HTML form controls. No server-side processing is implemented.
